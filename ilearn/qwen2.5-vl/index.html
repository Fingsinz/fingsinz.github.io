Qwen2.5-VL 技术报告粗读

关键词：深度学习、模型、模型、多模态

引言

Qwen2.5-VL 是千问团队在 2025 年发布的一个多模态模型 [1]，具有三种尺寸：Qwen2.5-VL-72B、Qwen2.5-VL-7B、Qwen2.5-VL-3B。

Qwen2.5-VL 的贡献有四个方面：

  1. 在视觉编码器中实现了 窗口注意力机制，优化推理效率；
  2. 引入了 动态帧率采样，将动态分辨率扩展到时间维度，从而实现跨不同采样率的全面视频理解；
  3. 将 MRoPE 与绝对时间对齐，在时间域中对其进行了升级，从而促进更复杂的时间序列学习；
  4. 在为预训练和监督微调精心策划高质量数据方面付出了巨大努力，进一步将预训练语料库规模从 120 万亿 tokens 扩展到 410 万亿 tokens。

Qwen2.5‑VL的突出特性如下：

  1. 强大的 文档解析能力 ：Qwen2.5‑VL将文字识别升级为全文档解析，擅长处理多场景、多语言
    以及各种内置（手写、表格、图表、化学公式和乐谱）文档。
  2. 跨格式精准物体定位 ：Qwen2.5‑VL实现了检测、指向和计数物体时更精准的定位，支持绝对坐
    标和JSON格式以进行高级空间推理。
  3. 超长视频理解和细粒度视频定位：我们的模型将原生动态分辨率扩展到时间维度，增强了理解数据的能力，
    小时视频的能力，同时能提取秒级的事件片段。
  4. 增强的智能体功能（适用于计算机和移动设备）：利用先进的定位、推理和决策能力，在智能手
    机和计算机上为模型提供更优越的智能体功能。

Qwen2.5-VL 模型架构

Qwen2.5-VL 模型整体由三部分组成：大语言模型（LLM）、视觉编码器（Vision Encoder） 和基于 MLP 的 视觉语言合并器（Vision Language Merger）。

LLM

Qwen2.5‑VL 使用 Qwen2.5 LLM 的预训练权重进行初始化。并且为了更好地满足多模态理解的需求，将1D RoPE（旋转位置嵌入）修改为与绝对时间对齐的多模态旋转位置嵌入。

Vision Language Merger

为了解决由长序列图像特征带来的效率挑战，所以特征序列输入 LLM 之前对其进行压缩，操作如下：

  1. 不直接使用由 ViT 提取的原始 Patch 特征，而是首先将空间上相邻的四个 Patch 特征进行分组；
  2. 将这些分组的特征进行拼接，并通过一个两层的 MLP 将其投影到与 LLM 中使用的 Text Embedding 维度相匹配的尺寸。

该方法不仅降低了计算成本，还提供了一种灵活的方式，可动态压缩不同长度的图像特征序列。

Vision Language Merger 的配置：

In Channel 1280 1280 1280
Out Channel 2048 3584 8192

# Layers 32 32 32

视觉编码器采用重新设计的 ViT 架构。在结构上，集成了 2D‑RoPE 和窗口注意力机制，以支持原生输入分辨率，同时加速整个视觉编码器的计算。在训练和推理过程中，输入图像的高度和宽度都会被调整到 28 的倍数，然后再输入到 ViT 中。视觉编码器通过以 14 的步长将图像分割成块来处理图像，生成一组图像特征。

为了缓解处理不同尺寸图像时存在的二次方计算复杂度 [2] 问题，重新设计 ViT 架构，引入窗口注意力机制。其中，只有四层采用全自注意力机制，其他层采用窗口注意力机制 [3]。

  • Qwen2.5-VL 中 Patch Size 默认为 14，窗口大小为 112，则窗口内的像素可被划分为 112 / 14 = 8，对应 8 × 8 个块。小于 112 × 112 的区域无需处理。
  • 以图 1 为例，假设 Patch Size 为 5，窗口大小为 10，merge size 为 2，则图中背景色区分不同的 Patch，外边框线区分不同的窗口。根据计算，该 20 × 20 的图像可被划分为 4 个窗口，每个窗口包含 4 个 Patch。经过窗口注意力计算后，每个窗口内部按照 merge size 融合，此处共融合得到 4 个融合 token。
    • 如果出现小于 20 × 20 的区域，那么无需处理，零碎区域不填充不补全直接处理。
    • 当每个窗口展开成一维索引序列时，由于窗口大小不一样导致序列长度不一致，此时需要 pad -100，后续注意力计算时把 index = -100 的位置全部 mask 屏蔽。
图1 窗口相关计算

对于位置编码，采用了二维旋转位置嵌入（RoPE）以有效捕捉二维空间中的空间关系。此外，为更好地处理视频输入，将方法扩展至三维块划分。

  • 使用 14 × 14 图像块作为基本单元，与传统静态图像的 ViT 保持一致。
  • 对于视频数据，将两个连续帧组合在一起，显著减少了 token 数量。

本地动态分辨率和帧率

Qwen2.5‑VL 在空间和时间维度上进行更新。

在空间域中，Qwen2.5‑VL 动态地将不同尺寸的图像转换为具有相应长度的 token 序列，并且直接使用输入图像的实际尺寸来表示边界框、点和其他空间特征。这使得模型能够内建地学习比例信息，提高其处理不同分辨率图像的能力。

对于视频输入，Qwen2.5‑VL 结合了动态帧率训练和绝对时间编码，即将 MRoPEID 直接与时间戳对齐，允许模型通过时间维度 ID 之间的间隔来理解时间的节奏，而无需任何额外的计算开销。通过适应可变的帧率，模型能够更好地捕捉视频内容的时序动态。

多模态旋转位置嵌入对齐到绝对时间

扩展 Qwen2‑VL 中引入的多模态旋转位置嵌入（MRoPE），以更好地处理视频中时间信息。Qwen2‑VL 中的 MRoPE 将位置嵌入分解为三个部分：时间、高度和宽度。

  • 对于文本输入，三个部分使用相同的位置 ID，使 MRoPE 在功能上等同于传统的 1DRoPE。
  • 对于图像输入，时间 ID 在视觉 token 中保持不变，而高度和宽度组件根据每个 token 在图像中的空间位置分配唯一 ID。
  • 对于视频输入，视频被视为帧序列，时间 ID 为每帧递增，而高度和宽度组件遵循与静态图像相同的分配模式。

然而，在 Qwen2‑VL 中，MRoPE 中的时间位置 ID 与输入帧数绑定，这并未考虑内容变化的速度或视频内事件发生的绝对时间。为了解决这一局限性，Qwen2.5‑VL 将 MRoPE 的时间分量与绝对时间对齐。

如图 2 所示，通过利用时间 ID 之间的间隔，模型能够学习到跨不同 FPS 采样率视频的一致时间对齐。
